# homebrew-tap

Homebrew tap for [mandaiy](https://github.com/mandaiy)'s macOS software.

## QuickLook Config

A Quick Look preview extension for YAML / JSON / TOML files.
See [mandaiy/quicklook-config](https://github.com/mandaiy/quicklook-config).

```sh
brew tap mandaiy/tap
brew install --cask quicklook-config
```

After installation, launch `QuickLookConfig.app` once so macOS registers the
Quick Look extension:

```sh
open "/Applications/QuickLookConfig.app"
```
